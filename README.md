# Uangku - Aplikasi Pencatat Keuangan Pribadi

**Uangku** adalah aplikasi web pencatat keuangan pribadi modern dan responsif (PWA) untuk melacak pemasukan, pengeluaran, anggaran, kalender, dan target tabungan. Data transaksi tersimpan secara lokal di browser menggunakan IndexedDB, dengan dukungan autentikasi Supabase dan fitur AI untuk scan struk serta konsultasi keuangan.

## Menjalankan Aplikasi

```bash
npm install
npm run dev
```

Untuk build produksi:

```bash
npm run build
npm start
```
